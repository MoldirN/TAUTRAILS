## О проекте

TAUTRAILS — это платформа для любителей активного отдыха в горах Алматы. Приложение позволяет пользователям:

- 🗺️ Просматривать каталог горных маршрутов
- 📸 Загружать фотографии и описания маршрутов
- 👤 Регистрироваться и авторизоваться на платформе
- 📝 Публиковать собственные маршруты

## Технологический стек

| Слой | Технология |
|---|---|
| **Backend** | Node.js, Express.js |

| **Стили** | SCSS |

## 🔒 Архитектура безопасности и сессий
1. **Access Token (`tt_access`):** Короткоживущий токен (7 дней) для быстрой авторизации запросов.
2. **Refresh Token (`tt_refresh`):** Долгоживущий токен (30 дней) для безопасного автоматического продления сессии.


## Спецификация API (Эндпоинты)
### 🔑 Аутентификация (`/api/auth`)
- `POST /login` — Вход пользователя.
- `POST /register` — Регистрация пользователя.
- `POST /logout` — Выход пользователя.
- `GET /my-reviews` — Получить отзывы текущего пользователя.
- `GET /me` — Получить текущего пользователя.

### 🏔️ Маршруты и Отзывы (`/api/trails`)
- `GET /stats` — Получить публичную статистику.
- `GET /` — Получить список маршрутов.
- `GET /:id` — Получить маршрут по ID.
- `POST /:id/reviews` — Добавить отзыв.
- `PUT /reviews/{id}` — Обновить отзыв.
- `DELETE /reviews/{id}` — Удалить отзыв.

### 🛡️ Панель админа (`/api/admin`) — *Только для роли admin*
- `GET /stats` — Получить стастистику сайта.
- `DELETE /trail-images/:id` — Удалить изображение маршрута.

- `GET /trails` — Получить все маршруты.
- `POST /trails` — Создать маршрут.
- `PUT /trails/:id` — Обновить маршрут.
- `DELETE /trails/:id` — Удалить маршрут.

- `GET /users` — Получить список пользователей.
- `PUT /users/:id/ban` — Заблокировать или разблокировать пользователя.
- `DELETE /users/:id` — Удалить пользователя.
- `PUT /users/:id/role` — Изменить роль пользователя.

- `GET /reviews` — Получить все отзывы.
- `PUT /reviews/:id/hide` — Скрыть или показать отзыв.
- `DELETE /reviews/:id` — Удалить отзыв.

## Установка и запуск

### Требования

- [Node.js](https://nodejs.org/) v16 или выше
- npm

### Шаги

1. **Клонировать репозиторий**

```bash
git clone https://github.com/MoldirN/TAUTRAILS.git
cd TAUTRAILS
```

2. **Установить зависимости**

```bash
npm install
```

3. **Скомпилировать стили**

```bash
npm run build-css
```

4. **Запустить приложение**

```bash
npm start
```

Приложение будет доступно по адресу: `http://localhost:3000`
