## О проекте

TAUTRAILS — это платформа для любителей активного отдыха в горах Алматы. Приложение позволяет пользователям:

- 🗺️ Просматривать каталог горных маршрутов
- 📸 Загружать фотографии и описания маршрутов
- 👤 Регистрироваться и авторизоваться на платформе
- 📝 Публиковать собственные маршруты

---

## Технологический стек

| Слой | Технология |
|---|---|
| **Backend** | Node.js, Express.js |
| **База данных** | SQLite (через sql.js) |
| **Аутентификация** | bcryptjs, express-session |
| **Загрузка файлов** | Multer |
| **Стили** | SCSS → CSS |
| **Dev-инструменты** | Nodemon, Sass |

## Установка и запуск

### Требования

- [Node.js](https://nodejs.org/) v16 или выше
- npm

### Шаги

1. **Клонировать репозиторий**

```bash
git clone https://github.com/MoldirN/TAUTRAILS.git
cd TAUTRAILS
```

2. **Установить зависимости**

```bash
npm install
```

3. **Скомпилировать стили**

```bash
npm run build-css
```

4. **Запустить приложение**

```bash
npm start
```

Приложение будет доступно по адресу: `http://localhost:3000`

## Скрипты

| Команда | Описание |
|---|---|
| `npm start` | Запуск в production-режиме (`node server.js`) |
| `npm run dev` | Запуск в режиме разработки с авто-перезагрузкой (`nodemon`) |
| `npm run build-css` | Компиляция SCSS в CSS |
